# Məhsul nişanları üzrə yoxlama — 7 noyabr 2026

Status: sənədlər və kommersiya istifadəsinin hüquqi əsası təsdiqlənməyib. Sahibin yoxlama istəyinə uyğun olaraq aşağıdakı məhsullar müvəqqəti Qaralama saxlanılır. Bu qeyddə hüquqi icazə və ya orijinallıq təsdiqi verilmir.

| Məhsul | Yoxlanacaq əsas | Yayıma qədər lazım olan sübut |
|---|---|---|
| DİN gerbi təsvirli ətirləndirici | Rəsmi idarə nişanına bənzər təsvir; yanlış rəsmi əlaqə təəssüratı | Məhsulun və nişan istifadəsinin hüquqi əsası, təchizat və təsvir/foto icazəsi |
| Qarabağ FK ətirləndiricisi | Klubun adı və emblemi; məhsul və foto hüquqları | Orijinal/lisenziyalı məhsul və ya tətbiq olunan qanuni satış əsası; klub nişanı və şəkil istifadəsi sənədləri |
| Azərbaycan bayrağı və gerbi təsvirli ətirləndirici | Dövlət rəmzlərindən kommersiya istifadəsinin xüsusi qaydaları və təsvirin düzgünlüyü | Tətbiq olunan qaydalara uyğunluq; məhsul və foto mənbə sənədləri |
| Bayraq formalı günəş enerjili ətirləndirici | Azərbaycan/Türkiyə bayraq təsvirlərinin istifadəsi | Müvafiq dövlət rəmzi qaydaları, təchizat və şəkil istifadəsi əsası |

Dövlət rəmzi klubun ticarət nişanı ilə eyni hüquqi rejimdə deyil; hamısı üçün eyni tip lisenziya tələb olunduğu nəticəsi çıxarılmır. Məhsul və materiallar üzrə ayrıca yoxlama tələb olunur. Marketplace-də mövcudluq icazə sənədi deyil. Orijinal və qanuni dövriyyəyə buraxılmış malın təkrar satışı ilə lisenziyasız nişan çapı ayrıca qiymətləndirilməlidir.

Rəsmi dövlət rəmzləri səhifəsi oxunub: https://president.az/az/pages/view/azerbaijan/symbols . Bu səhifə konkret məhsul üçün kommersiya icazəsi vermir. DİN səhifəsi https://mia.gov.az/az/ yoxlama zamanı503, klub səhifəsi https://qarabagh.com/az isə403 qaytardı; bunlardan hüquqi icazə çıxarılmır. Əmtəə nişanı reyestrindən konkret qeydiyyat və sahibdən yazılı icazə əldə edilməyib. Heç bir təşkilata mesaj göndərilməyib.

Admin məhsul redaktəsində hüquq yoxlaması işarəsi və sənəd istinadı var. Sənədləşdirilmiş yoxlamadan sonra işarə götürülüb məhsul yenidən yayımlana bilər. Cari şəkillər, stok və tarixi sifarişlər saxlanılır; qaralamaya keçid satış və açıq media girişini dayandırır.
